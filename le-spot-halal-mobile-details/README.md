# Le Comptoir — mobile restaurant details

Static HTML/CSS implementation of Figma frame `1:82` from file `mMPV21NfSMrHikvRVU0twE`.

Reference: 390 × 3961 px. The page scales down below 390 px and stays centered at a maximum width of 390 px. All controls are visual only; there is no JavaScript or form behavior.

## Assets

Run `python3 download-assets.py` from this folder to download the 14 images and icons listed in `asset-manifest.json` into `assets/`. Figma download links expire; refresh the manifest URLs if needed. Fonts and their licenses are included. Images intentionally await your download.

Open `index.html` or serve the folder with `python3 -m http.server 8000`.

`validation.json` records browser checks at 320, 375, 390, 430, and 768 px. At the reference width, all main section positions and heights match the Figma metadata. Asset appearance remains to be verified after download.
